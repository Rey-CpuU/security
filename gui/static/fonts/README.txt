8-Bit Pixel Typography Assets.
This directory provides local bundled pixel font definitions for 100% offline operation without Google Fonts or external CDN dependencies:
- press_start_2p.woff: Compact Web Open Font Format (3.5 KB)
- press_start_2p.ttf: TrueType OpenType font format (26.2 KB)
Declared via @font-face in gui/static/css/retro_8bit.css.
Generated via scripts/generate_pixel_font.py using fontTools FontBuilder.
